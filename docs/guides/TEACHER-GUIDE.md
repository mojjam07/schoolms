# Guide for teachers

## Your home page
**Home** shows the classes you teach, work waiting to be marked (oldest deadline first), upcoming deadlines with "n of N handed in", announcements and any unread messages.

## Lessons and assignments
- **Lesson notes** and **Video lessons**: add notes and files, or a YouTube link, for a class. Students see them under **My lessons**.
- **Assignments**: create one for a class and subject, set the deadline, publish it (students are notified), then mark each submission and give feedback. Students and their parents can see whether work is handed in, marked or late.

## Quizzes
Under **Quizzes** choose **New quiz**: pick the class and subject, write questions with several options and one correct answer, set how many marks each is worth, when it opens and closes, an optional time limit and how many attempts are allowed. Save it as a draft, check it, then **Publish to the class**. Marking is automatic. You see each student's best score and the class average. A published quiz cannot be edited: close it and make a new one. Closing submits anyone still taking it with the answers they have given.

## Scores and report cards
**Scores**: enter each pupil's scores in the columns the school set. Leave a box empty if a pupil has no score yet. A subject with a missing score shows "incomplete" and is left out of that pupil's average. Ask an administrator to publish results when scores are complete.

## Attendance (form teachers)
Form teachers take the register each school day. You can correct a register for 7 days; after that ask an administrator. Review absence explanations from parents: accept or decline, with a note.

## Messages with parents
Under **Messages** you can reply to parents of pupils you teach, and start a conversation with one of them. You will not see a parent's phone or email, and they will not see yours. Keep messages polite and about school matters. Administrators can read any conversation for safeguarding. Use **Report** on a message that worries you, and **Close conversation** when it is finished. You can only write to parents of pupils you currently teach.

## Notification settings
Choose what you want to be told about, in the app and by email. Account and security messages are always sent.

## Good practice
- Mark work promptly, so students and parents see progress.
- Never give your password to anyone, including students.
- If you see a pupil's work or information you should not, tell an administrator.
